# ผู้ใช้ กลุ่มผู้ใช้งาน และสิทธิ์

หน้าผู้ใช้และกลุ่มผู้ใช้งานใช้กำหนดว่าใครเข้าระบบได้ และแต่ละคนเห็นเมนูอะไรบ้าง

## 1. เพิ่มผู้ใช้ใหม่

1. ไปที่เมนูผู้ใช้ระบบแล้วกดปุ่มเพิ่มรายการใหม่
2. กรอกชื่อ อีเมล และชื่อผู้ใช้ (ภาษาอังกฤษ ตัวเลข จุด หรือขีดล่าง)
3. เลือกกลุ่มผู้ใช้งานให้ตรงกับบทบาท เช่น ผู้ดูแล หรือเจ้าหน้าที่
4. บันทึกแล้วแจ้งให้ผู้ใช้ตั้งรหัสผ่านของตัวเอง

## 2. สร้างกลุ่มและกำหนดสิทธิ์

1. ไปที่เมนูกลุ่มผู้ใช้งานแล้วกดเพิ่มกลุ่มใหม่
2. ตั้งชื่อกลุ่มให้สื่อความหมาย เช่น `content-editor`
3. ติ๊กสิทธิ์ที่ต้องการในรูปแบบ `<entity>_<action>` เช่น `app_user_list`
4. บันทึกแล้วทดสอบด้วยการล็อกอินเป็นผู้ใช้ในกลุ่มนั้น

## 3. ออก API client ให้ระบบอื่น

1. ไปที่เมนู API client สำหรับนักพัฒนา
2. สร้าง client ใหม่แล้วผูกกับผู้ใช้ที่เป็นเจ้าของ token
3. คัดลอก token ไปเก็บในที่ปลอดภัย ระบบจะไม่แสดงซ้ำ
4. ปิดหรือลบ token ทันทีเมื่อพบการใช้งานผิดปกติ

## ข้อควรระวัง

- สิทธิ์ฝั่งเว็บเป็นเพียงการซ่อนเมนู การอนุญาตจริงอยู่ที่เซิร์ฟเวอร์
- อย่าให้สิทธิ์ `delete` กับกลุ่มทั่วไปถ้าไม่จำเป็น
