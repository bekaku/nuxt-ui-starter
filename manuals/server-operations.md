# คู่มือติดตั้งและดูแลระบบ

สำหรับทีมดูแล server ตั้งแต่การติดตั้งครั้งแรกไปจนถึงงานเฝ้าระวังประจำวัน

## 1. ส่วนประกอบและการติดตั้ง

1. เตรียม server ตามสเปกขั้นต่ำที่ทีมกำหนด
2. ตั้งค่าที่ต้องตั้ง (environment) ให้ครบก่อน build ครั้งแรก
3. รันคำสั่ง build แล้วตรวจว่าไม่มี error
4. เปิด health check แล้วลองเรียกจากภายนอก

## 2. การอัปเดตและย้อนเวอร์ชัน

1. สำรองค่าตั้งต้นและข้อมูลสำคัญก่อนอัปเดตทุกครั้ง
2. อัปเดตทีละสภาพแวดล้อม จาก dev ไป staging แล้วค่อย production
3. เก็บ build เก่าไว้อย่างน้อย 1 เวอร์ชันเพื่อย้อนกลับได้ทันที

## 3. การรับมือการแจ้งเตือนและปัญหาที่พบบ่อย

- ตั้งการแจ้งเตือนเมื่อ service ล่มหรือ disk ใกล้เต็ม
- แยกปัญหาระหว่าง backend ล่มกับ frontend เรียกผิดก่อนแก้
- จดวิธีแก้ทุกครั้งเพื่อสะสมเป็น runbook ของทีม

## เช็กลิสต์ประจำสัปดาห์

- [ ] ตรวจ log error ย้อนหลัง 7 วัน
- [ ] ตรวจพื้นที่ disk และใบรับรอง HTTPS
- [ ] ตรวจ backup ว่ากู้คืนได้จริง
