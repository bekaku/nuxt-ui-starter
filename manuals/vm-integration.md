# คู่มือเชื่อมต่อสำหรับ VM ของวิทยาลัย

คู่มือสำหรับนักพัฒนาฝั่งวิทยาลัย (VM) ที่ต้องการเชื่อมข้อมูล เช่น รายชื่อนักศึกษา เอกสาร และสิทธิ์การใช้งาน

## 1. ภาพรวมการเชื่อมต่อ

- VM เป็นฝั่งเจ้าของข้อมูลนักศึกษาและเอกสารของวิทยาลัย
- Admin console เป็นฝั่งเรียกดูภาพรวมและเรียกใช้ข้อมูลผ่าน API
- ทุกคำขอต้องแนบข้อมูลระบุตัวตน (person context) ตามคู่มือเรื่องถัดไป

## 2. ขั้นตอนฝั่ง VM

1. ยืนยันตัวตนตามสเปกที่ทีมกลางกำหนด
2. ส่งเอกสาร บทวิเคราะห์ และผลการเรียกแยกตามผู้ใช้
3. เก็บ log การเรียกไว้ฝั่ง VM เพื่อตรวจสอบย้อนหลัง

## 3. การแยกสิทธิ์ข้อมูล

- ข้อมูลแต่ละวิทยาลัยต้องแยกออกจากกันชัดเจน
- ผู้ใช้เห็นเฉพาะข้อมูลของวิทยาลัยตัวเองเท่านั้น
- ก่อนเปิดให้ใช้งานจริง ให้ทดสอบด้วยบัญชีของแต่ละวิทยาลัย

## ติดต่อทีมกลาง

เตรียมตัวอย่าง request/response จริงมาด้วยทุกครั้งที่แจ้งปัญหา จะช่วยให้ตรวจสอบได้เร็วขึ้น
