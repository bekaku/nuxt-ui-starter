# คู่มือเชื่อมต่อ LLM Gateway

สำหรับนักพัฒนาระบบอื่นที่ต้องการเรียกโมเดลผ่าน gateway ด้วยรูปแบบเดียวกับ OpenAI

## 1. เตรียมตัวก่อนเรียก

1. ขอ API key จากผู้ดูแลระบบ
2. ดูรายชื่อโมเดลที่เปิดให้ใช้ด้วย endpoint รายการโมเดล
3. เตรียม base URL ของ gateway ให้ตรงตามสภาพแวดล้อม

## 2. การเรียกใช้งานหลัก

- `GET /v1/models` ดูรายชื่อโมเดลที่ใช้ได้
- `POST` chat completions สำหรับงานสนทนาและสรุปความ
- `POST` embeddings สำหรับงานค้นหาความหมาย (semantic search)

## 3. แนวทางสำหรับ production

1. ตั้ง timeout และ retry แบบ exponential backoff
2. ส่ง streaming เมื่อต้องการแสดงผลทีละส่วน
3. เก็บ log แบบไม่บันทึกข้อมูลส่วนบุคคลที่ไม่จำเป็น
4. แยกคีย์และโควตาตามแต่ละงานเพื่อคุมค่าใช้จ่าย

## การแก้ปัญหาเบื้องต้น

- `401` ตรวจว่าแนบ API key ถูกต้องและยังไม่หมดอายุ
- `429` ลดความถี่การเรียกหรือขอเพิ่มโควตา
- ผลลัพธ์ผิดปกติ ตรวจชื่อโมเดลและพารามิเตอร์ที่ส่งไป
