# ภาพรวม API สำหรับนักพัฒนา

ภาพรวมกลุ่ม API ของระบบ วิธีพิสูจน์ตัวตน สิทธิ์ รูปแบบ response และ error ที่นักพัฒนาต้องรู้ก่อนลงมือ

## 1. กลุ่มของ API

- กลุ่มผู้ใช้และสิทธิ์: จัดการผู้ใช้ กลุ่ม และเมนูโปรด
- กลุ่มเอกสาร AI: อัปโหลดเอกสารและถามตอบ
- กลุ่มไฟล์: อัปโหลดแบบ chunk และจัดการโฟลเดอร์

## 2. การยืนยันตัวตนและสิทธิ์

1. ล็อกอินเพื่อรับ cookie session (HttpOnly)
2. แนบ session ไปกับทุกคำขอที่ต้องยืนยันตัวตน
3. สิทธิ์จริงตัดสินที่เซิร์ฟเวอร์ ฝั่งเว็บซ่อนเมนูเพื่อประสบการณ์ใช้งานเท่านั้น

## 3. รูปแบบ response และ error

- สำเร็จ: ตรวจ HTTP status `200` แล้วอ่านข้อมูลใน body
- รูปแบบห่อมาตรฐาน `ApiResponse<T>` หรือ array เปล่า `T[]` ให้รองรับทั้งสองแบบ
- `error` และ `id` ใน response ใช้ตามรหัสนานาชาติ อย่าเดาความหมายจากข้อความ

## 4. การแบ่งหน้าและ streaming

1. ส่งพารามิเตอร์แบ่งหน้าทุกครั้งเมื่อดึงรายการ
2. ใช้ streaming เฉพาะ endpoint ที่รองรับ แล้วต้องจัดการ abort ให้ดี
3. อย่าถือว่าไฟล์ที่อัปโหลดเสร็จพร้อมใช้ทันที (ingestion เป็น async)
