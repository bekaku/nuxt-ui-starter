Playground มีไว้ให้ผู้ทดลองโมเดลเปรียบเทียบพฤติกรรมของแต่ละโมเดลก่อนเอาไปใช้จริง

## 1. เริ่มทดลอง

1. เปิดหน้า Playground แล้วเลือกโมเดลของ gateway
2. เลือกรูปแบบการตอบ เช่น ตอบทันทีหรือแบบ streaming
3. พิมพ์คำถามทดสอบแล้วกดส่ง

## 2. เปิด/ปิดการคิดและแก้ปัญหา

- เปิดโหมดแสดงขั้นตอนคิดเมื่อต้องการดูเหตุผลของโมเดล
- ปิดโหมดนี้เมื่อต้องการคำตอบสั้นและเร็ว
- ถ้าคำตอบเพี้ยน ให้ลองลดอุณหภูมิ (temperature) หรือเขียน prompt ใหม่

## 3. บันทึกผลการทดลอง

1. จด prompt โมเดล และค่าตั้งต้นที่ใช้ทุกครั้ง
2. เปรียบเทียบคำตอบอย่างน้อย 2-3 โมเดลก่อนตัดสินใจ
3. ส่งต่อ prompt ที่ดีที่สุดให้ทีมพัฒนาไปใช้ในระบบจริง

## หมายเหตุ

- ผลใน Playground อาจไม่เหมือน production ถ้าตั้งค่าต่างกัน
- อย่าใส่ข้อมูลลับขององค์กรในคำถามทดสอบ
