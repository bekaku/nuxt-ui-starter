สรุปภาพรวมสำหรับผู้บริหารว่า ระบบช่วยงานอะไร ใครใช้งาน และต้องกำกับดูแลเรื่องใดบ้าง

## 1. ระบบช่วยอะไร

- รวมงานผู้ดูแล นักพัฒนา และทีมเชื่อมต่อไว้ในที่เดียว
- ลดงานซ้ำซ้อนด้วยคลังความรู้กลางและการค้นหาที่รวดเร็ว
- ติดตามสถานะระบบและการแจ้งเตือนทางอีเมลได้จากหน้าเดียว

## 2. ใครใช้งาน

1. ผู้ดูแลระบบ: จัดการผู้ใช้ สิทธิ์ และเอกสารกลาง
2. นักพัฒนา: เชื่อมต่อ API และทดสอบโมเดล
3. ผู้บริหาร: ดูภาพรวมและการแจ้งเตือนความเสี่ยง

## 3. การกำกับดูแลความเสี่ยง

- ทบทวนสิทธิ์ผู้ใช้และคีย์ API อย่างน้อยไตรมาสละครั้ง
- แยกข้อมูลตามวิทยาลัยและห้ามแชร์บัญชีกัน
- วางแผนรับมือข้อมูลปัจจุบันแบบไม่ใช้ศัพท์เทคนิคเกินไป

## ตัวชี้วัดที่ควรดู

- จำนวนผู้ใช้ที่ยัง active รายเดือน
- จำนวนคำถามที่ AI ตอบไม่ได้ (นำไปปรับปรุงเอกสาร)
- ระยะเวลาตอบสนองเมื่อระบบมีปัญหา
