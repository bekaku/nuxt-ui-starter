หน้านี้สำหรับผู้ดูแลระบบที่ต้องออก แก้ไข และหมุนเวียน (rotate) คีย์สำหรับเรียกโมเดลผ่าน gateway

## 1. ออกคีย์ใหม่

1. ไปที่หน้าจัดการคีย์ของ LLM Gateway
2. กดสร้างคีย์ ตั้งชื่อให้รู้ว่าใช้กับงานอะไร
3. กำหนดวันหมดอายุและโควตาให้เหมาะกับงาน
4. คัดลอกคีย์ไปเก็บในที่ปลอดภัยทันที

## 2. แก้ไขและ rotate คีย์

1. เลือกคีย์ที่ต้องการแล้วกดแก้ไขเพื่อปรับโควตาหรือสถานะ
2. เมื่อต้องการ rotate ให้ออกคีย์ใหม่ก่อน แล้วค่อยปิดคีย์เก่า
3. อัปเดตคีย์ในแอปที่เรียกใช้ แล้วเฝ้าดู error สัก 15-30 นาที

## 3. ดูการใช้งาน

- ดูปริมาณการเรียกแยกตามคีย์ โมเดล และช่วงเวลา
- ตั้งจุดสังเกตเมื่อยอดพุ่งผิดปกติหรือ error เพิ่มขึ้น
- ปิดคีย์ที่ไม่มีการใช้งานนานแล้วเพื่อลดความเสี่ยง

## ข้อควรระวัง

- คีย์เปรียบเหมือนรหัสผ่าน ห้ามวางในโค้ดฝั่งเบราว์เซอร์
- แยกคีย์ตามสภาพแวดล้อม dev/staging/production เสมอ
